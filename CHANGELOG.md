# Changelog

Framekit release entries are generated by `pnpm release:prepare -- --version <semver> --write`.

## Unreleased

- Updated Nano ID and Vitest to patched versions and made the dependency-security gate reject advisories at every severity.
- Bound OIDC browser callbacks to a short-lived HttpOnly flow cookie, preventing cross-browser login CSRF.
- Invalidated signed sessions after password changes/recovery, rejected API tokens whose bound user was deleted, and required verified email for provider email auto-linking. Existing signed sessions require a fresh sign-in after this upgrade.
- Replaced stale full-user authentication updates with atomic login-state and credential mutations so concurrent requests cannot undo password resets, account disabling, or permission changes. Custom `UserStore` adapters must implement the new atomic methods before upgrading; see `docs/identity.md`.
- Added explicit runtime, database, queue/worker, and realtime lifecycle and cancellation contracts.
- Added OpenTelemetry-compatible request adapters, secret redaction, and split liveness/readiness probes with bounded dependency checks.
- Added tested compatibility, coverage, CodeQL, Dependabot, dependency audit, SBOM, security disclosure, contribution, and support policies.
- Added generated typed SDK errors, opt-in bounded retries for safe/idempotent requests, cancellation, and deterministic versioned client-config upgrades.
- Moved Desk authentication from browser-stored bearer tokens to HttpOnly session cookies, including session restoration and expired-session browser coverage.
- Added service-backed Postgres coverage thresholds, default/development package-export parity checks, root lint enforcement in CI, immutable action pins, and least-privilege SBOM permissions.
- Hardened the local/reference Compose stack by binding Postgres and Redis to loopback and supporting paired raw-password and percent-encoded connection-URL overrides; production deployments require separately provisioned private or managed services and credentials.

## 0.1.0 - 2026-07-21

- Added the initial metadata runtime, Nitro API, authentication, persistence adapters, SDK, CLI, and Desk.
- Added standalone tarball/consumer verification and tag-gated provenance publishing.
